# STUDEX: запуск через GitHub

Что здесь: готовый проект. Интерфейс (index.html + backend.js) размещается на GitHub Pages, сервер (supabase/functions/api) и база (supabase/migrations) работают в Supabase. Всё на бесплатных тарифах.

Что работает по-настоящему: вход через Telegram с проверкой подписи на сервере, регистрация по кодам (одноразовые, в базе только хеши), номера пользователей, роли (покупатель, продавец, администратор, директор), предложения продавцов, объявления покупателей, заказы с проверкой переходов на сервере, чат по заказу, комиссия 20% и долг по каждому продавцу, наличные расчёты, жалобы, блокировки, журнал действий, уведомления через бота.

Чего пока нет: отправка файлов в чате, двухфакторная защита администраторов, резервная копия директора, TOTP. Это следующие этапы. Проект ещё ни разу не запускался на вашем Supabase, поэтому при первом запуске возможны мелкие ошибки: присылайте текст ошибки или скриншот.

## 0. Что должно быть готово

1. Бот в @BotFather и его токен (`/newbot`). Токен храните только у себя.
2. Аккаунт GitHub и аккаунт Supabase (вход через GitHub).

## 1. Supabase: база

1. supabase.com, New project: название studex, пароль базы сохраните у себя, регион Frankfurt, тариф Free.
2. SQL Editor, New query: вставьте весь `supabase/migrations/001_schema.sql`, Run. Должно быть Success.
3. Ещё один New query: вставьте весь `studex_code_hashes.sql`, Run.
4. Проверка: выполните `select role, count(*) from invitation_codes group by role;`. Ожидаемо: admin 20, director 5, seller 150.
5. Project Settings, API: скопируйте Project URL и anon public key. Они понадобятся в шаге 4. Из этого же раздела Project ID (он же ref) понадобится в шаге 3.
6. Edge Functions, Secrets, Add new secret: имя `BOT_TOKEN`, значение токен бота. Больше секретов добавлять не нужно.
7. Account (аватар справа вверху), Access Tokens, Generate new token: назовите github-deploy и сохраните токен у себя.

## 2. GitHub: репозиторий

1. github.com, New repository: имя `studex`, Public.
2. Add file, Upload files: перетащите всё содержимое распакованного архива (index.html, backend.js, config.js, README.md, studex_code_hashes.sql, папку supabase). Commit changes.
3. Папка `.github` скрытая и часто не загружается перетаскиванием. Создайте файл вручную: Add file, Create new file, в поле имени введите `.github/workflows/deploy-functions.yml` и вставьте содержимое файла из архива. Commit.

## 3. GitHub: деплой сервера

1. Settings, Secrets and variables, Actions, New repository secret. Два секрета:
   - `SUPABASE_ACCESS_TOKEN`: токен из шага 1.7;
   - `SUPABASE_PROJECT_REF`: Project ID из шага 1.5.
2. Вкладка Actions, Deploy Supabase function, Run workflow. Дождитесь зелёной галочки.
3. Проверка: в Supabase, Edge Functions, должна появиться функция `api`.

## 4. GitHub: подключение интерфейса к серверу

1. Откройте в репозитории `config.js`, значок карандаша.
2. Впишите Project URL и anon public key (оба публичные, их можно хранить в репозитории). Commit.

## 5. GitHub Pages и Telegram

1. Settings, Pages, Deploy from a branch, main, / (root), Save. Через 1–3 минуты появится адрес `https://ВАШ_ЛОГИН.github.io/studex/`.
2. @BotFather: `/mybots`, ваш бот, Bot Settings, Menu Button, Configure menu button: отправьте адрес из пункта 1 и название кнопки.
3. Откройте бота, нажмите кнопку меню.

## 6. Первый вход

1. Откройте бота: сначала экран регистрации. Директору нажать «Войти по коду» справа вверху, ввести директорский код (75 символов), поставить галочку, «Войти».
2. Остальным: продавцам коды по 25 символов, администраторам по 50. Покупатели нажимают «Начать» без кода. Один код подходит одному человеку.
3. Проверка по порядку: продавец публикует предложение (Профиль, Мои предложения), покупатель заказывает, продавец называет сумму, покупатель принимает и сообщает об оплате, продавец подтверждает, сообщает о выполнении, администратор утверждает, покупатель подтверждает. У директора и администратора появляется долг продавца.

## Обновление 

Изменили файл на GitHub: интерфейс обновится через 1–2 минуты (закройте и откройте приложение). Изменили `supabase/functions/**`: сервер обновится сам через Actions.

## Безопасность

- Токен бота, токен GitHub и пароль базы никому не показывать и не вставлять в чат.
- Файл `studex_codes_SECRET.csv` в репозиторий не загружать. После раздачи кодов удалить.
- Тексты правил не проходили юридическую проверку.
